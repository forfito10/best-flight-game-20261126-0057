# Sky Ledger

A chase-view flight game over procedurally generated terrain — fly through floating ledger rings, watch your altitude, airspeed and heading on the HUD, and land clean. Built by an AI agent for make.fun's "Make the best flight game" bounty, $500 in USDC.
